# Glossário rápido

Esta semente usa algumas palavras de "mundo dev". Você **não precisa** ser programador para
usar uma KB — mas vai cruzar com estes termos. Aqui está cada um em linguagem direta. Volte
aqui sempre que travar numa palavra.

| Termo | Em uma frase | Analogia de marketing |
| --- | --- | --- |
| **Repositório (repo)** | a pasta da sua KB, hospedada no GitHub | é o "Drive" do seu conhecimento, com histórico |
| **Markdown (.md)** | jeito simples de escrever texto com títulos e listas | como escrever no WhatsApp com `*negrito*` |
| **Frontmatter** | um cabeçalho no topo do arquivo com etiquetas | as "tags" e a "categoria" de um post |
| **YAML** | o formato dessas etiquetas (`chave: valor`) | preencher um formulário simples |
| **`type` (tipo)** | etiqueta que diz o papel da nota (mapa, tese, mensagem…) | a "categoria" de um conteúdo |
| **Commit** | salvar uma versão com um nome | "salvar como…" deixando registro de quem e quando |
| **Branch** | uma cópia paralela para mexer sem bagunçar o original | um rascunho separado antes de publicar |
| **Pull Request (PR)** | pedido para juntar seu rascunho ao original, com revisão | mandar a peça para aprovação antes de subir |
| **Canônico** | a versão oficial, validada, "fonte da verdade" | o manual de marca aprovado |
| **Derivado** | material feito a partir do canônico (resumo, post) | um carrossel feito a partir do white paper |
| **Promover** | levar algo amadurecido para a camada oficial | tirar uma ideia do rascunho e oficializar |
| **Handoff** | um bilhete de passagem para quem continua o trabalho | o briefing que você deixa para o colega |
| **MCP** | um jeito de agentes de IA lerem sua KB como contexto | dar à IA acesso ao seu "manual de marca" |
| **OKF** | um padrão aberto de organizar conhecimento em arquivos | uma norma de boas práticas, como um guia de estilo |

## A regra que resume tudo

> Sua KB é **texto simples**, guardado com **histórico**, que **humanos e IAs** conseguem ler.
> Todo o resto é detalhe.

Não decore esta tabela. Comece pela [primeira KB em 15 minutos](04_primeira-kb-em-15-min.md) e
volte aqui quando precisar.
